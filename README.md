# Phần Mềm Nhận Dạng Khuôn Mặt (Face Recognition System)

## 1. Giới thiệu dự án
Hệ thống sử dụng xử lý ảnh và Học máy (Machine Learning) để phát hiện và nhận dạng khuôn mặt trong hình ảnh hoặc webcam.

## 2. Thành viên nhóm & Phân công công việc
* **Thành viên 1 (Nhóm trưởng):** Quản lý dự án, thiết kế kiến trúc hệ thống & xây dựng luồng dữ liệu (Data Pipeline).
* **Thành viên 2:** Thu thập, làm sạch dữ liệu hình ảnh & Huấn luyện mô hình nhận dạng (Model Training).
* **Thành viên 3:** Xây dựng giao diện người dùng (UI/UX) và hiển thị kết quả trực quan.
* **Thành viên 4:** Tích hợp mô hình với giao diện, thực hiện kiểm thử (Testing) & viết tài liệu dự án.

## 3. Công nghệ sử dụng
* Ngôn ngữ: Python
* Thư viện: OpenCV, Face_Recognition / Dlib, Tkinter hoặc PyQt
